🛠️ Big Data Tools Employed in DHAP-Net

The DHAP-Net pipeline integrates 6 specialized big data technologies across the ingestion, stream aggregation, distributed graph mining, machine learning, and visual analytics layers:

1. Apache Kafka

Role: High-throughput distributed stream ingestion.
Usage: Replays historical NetFlow events into topic dhapnet.flows with source-host partitioning, processing up to 560,000 records/sec with zero data leakage.

2. Spark Structured Streaming

Role: Rolling tumbling-window stream ETL.
Usage: Consumes micro-batches, groups by (hour, src, dst, protocol), reducing 130M flows down to 14.8M compacted edges (88.6% reduction).

3. Hadoop HDFS

Role: Fault-tolerant distributed data storage.
Usage: Stores partitioned micro-batched Parquet streams at /dhapnet/flows, enabling scalable distributed I/O across worker clusters.

4. Spark GraphFrames

Role: Distributed BFS graph extraction.
Usage: Computes $k=2$ hop candidate attack frontiers from compromised seed hosts $\mathcal{C}_t$, pruning 97.2% of non-viable host pairs and eliminating $\mathcal{O}(N^2)$ combinatorial explosion.

5. Apache Spark MLlib

Role: Distributed baseline machine learning.
Usage: Trains scalable Random Forest (200 trees) on distributed candidate feature vectors across multi-core Spark executors.

6. Neo4j (Browser & Bloom)

Role: Native graph database & visual analytics.
Usage: Stores host topology, COMMUNICATES_WITH edges, and DHAP-Net SIMULATED_PROPAGATION paths with continuous risk properties for Cypher queries and Bloom exploration.
